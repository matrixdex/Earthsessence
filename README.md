# Earthsessence

Static site: `index.html`, `products.html`, `benefits.html`, shared `styles.css` and `script.js`. Open any page in a browser, or serve the folder with `python3 -m http.server`.

Motion lives in the `--spring`, `--ease-out` and `--dur-*` tokens at the top of `styles.css`. `prefers-reduced-motion`, `prefers-reduced-transparency` and `prefers-contrast` are all honoured.
